# Brew You — Coffee Personality Quiz

A playful, pop-culture coffee personality quiz. Answer six questions to discover your coffee persona and a matching drink recommendation.

**Live site:** https://hrvojep.github.io/quiz-project/

## Run locally

This is a static site—no dependencies or build step are required.

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open `http://localhost:4173`.

## Deployments

GitHub Pages deploys automatically when changes are pushed to `main`. The workflow lives in `.github/workflows/deploy-pages.yml`.
